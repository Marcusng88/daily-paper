# Design languages

Choose one visual language that matches the paper's intellectual character; do not combine several decorative themes.

- **Academic notebook:** generous reading measure, serif body text, quiet margins, annotation-like callouts. Good for theory and derivations.
- **Technical atlas:** a strong central diagram, restrained sans-serif labels, carefully bounded colour. Good for systems and architectures.
- **Evidence ledger:** results-led hierarchy, precise tables and figure callouts, muted analytical colour. Good for empirical comparisons.

Start with the paper's strongest learning obstacle, then choose type, colour, layout, and the signature explanatory visual to reduce it. A design is successful when it improves navigation and explanation without competing with the evidence.
