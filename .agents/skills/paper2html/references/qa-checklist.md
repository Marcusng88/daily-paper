# HTML QA checklist

## Factual

- Every result, caption, equation, author, and link matches the PDF or canonical record.
- Original figures are sharp enough to read and custom diagrams are clearly labeled.

## Functional

- The document and embedded JavaScript parse.
- All local paths resolve; no placeholder `href` remains.
- Keyboard interactions work and non-interactive reading still conveys the lesson.

## Visual

- Inspect desktop and narrow mobile widths when rendering is available.
- No horizontal overflow, clipping, distorted figures, unintentional overlap, or unreadable contrast.
- The Home link and source footer work when the lesson is part of a collection.
