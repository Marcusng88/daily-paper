Depth works better when a layer can revise.

ResNet reframes a hard request - “learn the next representation” - as a more forgiving one: “keep what is useful, and learn the correction.”

01 / The prerequisite bridge

First separate two failures that look alike.

More capacity can harm test performance through overfitting. ResNet starts from a sharper observation: some deeper plain networks had worse training error too.

That is the degradation problem. A deeper architecture should be able to imitate a shallower one by making added layers act like identities, yet the available solver did not reliably find that solution.

A useful diagnostic

Training error rises with depth: suspect optimization first. Training error is low but validation error rises: suspect generalization. The distinction changes what a fix should target.

Lesson diagram The function class contains the shallow solution; the paper’s point is that parameterization affects how easily optimization can reach it.

02 / The central mechanism

Give every block a baseline it can preserve.

Let H(x) be the transformation a stack should produce. Rather than learning H directly, the stack learns F(x) = H(x) − x. The shortcut adds the original input back.

Lesson diagram This is the original paper’s post-activation form: for the pictured two-layer branch, the second ReLU follows the addition.

Predict before reveal

03 / Work the notation

Trace a block before you name it.

The symbols become concrete when we follow one feature map through a two-layer residual block.

  1. Receive a feature map

    Suppose x has shape 56 × 56 × 64: 56 by 56 locations and 64 channels at each location.

  2. Compute a learned proposal

    Two 3×3 convolutions form F(x, {Wᵢ}). If they preserve the shape, F(x) is also 56 × 56 × 64.

  3. Add position by position, channel by channel

    y[h,w,c] = F(x)[h,w,c] + x[h,w,c]. Addition is not concatenation: it produces one revised feature map.

  4. Apply the paper’s following nonlinearity

    In the original paper’s pictured block, the second ReLU comes after the sum. The additive parameterization is the core lesson; later residual variants use other orderings.

When shapes match

Use an identity shortcut. It carries x directly, with no learned parameters or convolutional computation.

When they do not

Use a compatible shortcut. The paper considers zero padding or a learned 1×1 projection, Wₛx, and uses stride 2 when crossing feature-map scales.

Lesson diagram A 1×1 convolution has a 1×1 spatial footprint, but it reads and mixes the full channel vector at each sampled location. Stride changes spatial resolution; learned filters change channel count.

04 / What the paper establishes

The clean comparison keeps the architecture almost fixed.

The strongest demonstration is not merely a high score. It compares 18- and 34-layer networks with the same broad design, then changes whether shortcut connections turn them into residual networks.

Plain27.94% top-1 error28.54% top-1 errorMade validation error worse; the deeper plain net also had higher training error.
Residual (Option A)27.88% top-1 error25.03% top-1 errorImproved validation error; the deeper residual net also reached lower training error.

ImageNet validation, 10-crop testing, Table 2. Option A uses identity shortcuts with zero padding for increased dimensions, so residual models have no extra parameters relative to plain counterparts.

Result

Depth became useful again.

For these models, the 34-layer residual network improves on its 18-layer counterpart by 2.85 percentage points in top-1 error.

1×1 reduce, 3×3 process, 1×1 restore. The costly spatial convolution runs in a narrower channel space.

Read the landmark result precisely

The paper reports 21.43% top-1 and 5.71% top-5 ImageNet validation error for a single ResNet-152 under 10-crop evaluation (Table 3). Its ILSVRC 2015 ensemble reports 3.57% top-5 test error (Table 5). These are historical benchmark results, not a claim that this 2015 architecture remains the best modern vision model.

05 / Bound the claim

Residual connections are a parameterization, not magic.

The paper distinguishes degradation from classic vanishing or exploding gradients. Its plain ImageNet networks use batch normalization, and the authors report healthy backward gradient norms; yet the deeper plain model still trains less well.

That supports a narrower, durable claim: making the identity baseline explicit can make very deep systems easier to optimize.

Common misconception

“Residual means the learned update must be tiny.” No. The branch can make a large change. “Residual” means it is learned relative to x; zero is simply a convenient baseline when little change is needed.

Predict: A 34-layer model has higher training error than an 18-layer model. Is that ordinary overfitting?

No. Higher training error makes degradation/optimization the primary diagnosis. Overfitting refers to a generalization gap where training performance is good but held-out performance worsens.

Predict: Can an identity shortcut add a 56 × 56 × 64 input to a 28 × 28 × 128 residual output?

No. Addition requires matching height, width, and channels. The shortcut must be aligned, for example by a stride-2 projection or by the paper’s zero-padding approach for increased dimensions.

Predict: Did the paper show that increasing depth always improves accuracy?

No. It showed compelling improvements for its residual architectures and settings. Its 1202-layer CIFAR-10 experiment achieved very low training error but worse test error than its 110-layer model, which the authors discuss as overfitting on the small dataset.

06 / Connect it to your mental map

Look for “baseline plus revision” across deep learning.

Transformers
Attention and feed-forward sublayers revise a token representation through residual additions. The object is different - tokens rather than visual feature maps - but the optimization-friendly idea is the same.
Batch normalization
BatchNorm manages activation statistics; residual shortcuts preserve an explicit information path. The ResNet paper uses BN, so treat them as complementary components.
DQN
DQN’s replay buffer and target network stabilize a moving bootstrapped target, not representation depth. Both papers show that reformulating a difficult learning dynamic can matter as much as raw capacity.
GANs
Residual blocks can be useful components in a generator or discriminator, but they do not solve the separate adversarial game between those two networks.

Question to carry forward

When you meet a very deep architecture, ask: What travels unchanged? What is learned as a correction? What makes the two paths compatible when they meet?

07 / Takeaway

A residual block is a revision layer.

It does not need to recreate its incoming representation from scratch. It gets a direct route for the useful baseline and learns evidence for changing it. That makes “do nearly nothing” and “make a useful correction” nearby choices for optimization.
