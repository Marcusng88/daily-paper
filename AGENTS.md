# Project instructions

## Project-scoped skills

The shareable skills for this Daily AI Paper collection live in `.agents/skills/`:

- `daily-ai-paper-lesson`
- `paper2html`
- `paper-lesson-visuals`
- `frontend-design`

Use these project-scoped copies for work on this collection. If a task changes one of these lesson-related skills, make the same change to the matching project-scoped copy in this repository as part of that work. Do not treat the local user-level copy as the only source of truth for this project.

The built-in `pdf` skill remains an environment-provided dependency and is intentionally not vendored here.
