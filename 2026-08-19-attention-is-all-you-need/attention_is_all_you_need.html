A one-hour guided study

Attention Is All You Need

The Transformer replaces a single-file procession through a sentence with learned, content-dependent communication: each token decides which other tokens can improve its representation.

The paper’s bet

For sequence transduction, recurrence and convolution are not necessary as the central mechanism. An encoder and decoder built from attention and position-wise feed-forward networks can translate well while exposing much more parallel work during training.

A credible study route

0–8 minEstablish the communication mental model and separate self-attention from cross-attention.
8–22 minWork a numerical attention pass. Map each symbol in the equation to an operation and a tensor shape.
22–35 minLearn why several heads, positions, residual paths, and feed-forward layers are needed.
35–47 minTrace causal masking and encoder-decoder generation; predict before revealing the result.
47–60 minRead the evidence carefully, name limitations, then use active recall and the mental-map bridge.

1. First intuition: communication, not a lookup table

Imagine a seminar. Each participant holds a note about one word. When a participant updates their note, they do not receive one fixed summary of the room. They ask a question tailored to their current role, listen more to some participants than others, and write a new note from the weighted replies. That is one attention round.

QueryWhat am I looking for?
A request made by the current token.
KeyWhat kind of information do I offer?
A label that a query can compare with.
ValueWhat information do I contribute?
The content blended into the updated token.

Keep the separation straight. Keys decide who is relevant. Values decide what is received. They are learned projections of the same incoming representation, but they serve different jobs.

2. The core operation, mapped precisely

For a sequence of n token representations in X ∈ Rn×dmodel, a single attention head learns three matrices:

Q = XWQ,   K = XWK,   V = XWV
Attention(Q,K,V) = softmax(QKT / √dk)V
ObjectShape for one headMeaning
Q, Kn × dkOne query/key vector for every position.
QKTn × nEvery row is one token asking how much each token matters to it.
A = softmax(…)n × nRow-normalized weights: each row sums to 1.
AVn × dvOne weighted mixture of values for every token.

The division by √dk is not decoration. With independent, zero-mean components, a dot product’s variance grows with dimension. Scaling prevents softmax from becoming one-hot too early and preserves useful gradients.

3. Worked trace: calculate one attention row

These small vectors are a lesson calculation, not weights from the paper. Let the query be the pronoun it: q=[1,0]. Three tokens offer keys and values:

TokenKeyValue
animal[2,0][1,0]
street[-1,1][0,1]
tired[1,0][1,1]
dk = 2
scores = qKT / √2 = [2, −1, 1] / √2 ≈ [1.41, −0.71, 0.71]
softmax(scores) ≈ [0.62, 0.07, 0.31]
output = 0.62[1,0] + 0.07[0,1] + 0.31[1,1] ≈ [0.93, 0.38]

The result is not a hard pointer to animal. It is a new representation dominated by animal, with a smaller contribution from tired. A different query row would use different weights over the same values.

Check your interpretation: why does street still get a nonzero weight?
Softmax makes all finite scores positive. The model can make a weight tiny, but this toy calculation does not completely forbid street. A mask, by contrast, creates a forbidden connection whose post-softmax weight is zero.

4. Predict first: which connections are legal?

Suppose the decoder is trained on target tokens <start> Das Tier schläft. Before looking at the answer, decide: when forming the representation at target position 3, should it be allowed to attend to position 4, schläft?

Rows are querying positions; columns are readable positions. Green means allowed. Red means blocked.

No. Position 3 may use positions 1–3, never position 4. During training, the whole known target can be processed in parallel, but forbidden entries are set to a very negative value before softmax. Their probability becomes zero. At generation time, the model only has the prefix it has already produced, so it still emits one next token at a time.

Important distinction: attention enables parallel computation across known positions during training. It does not make an autoregressive translation appear all at once during inference.

5. Why multi-head attention is not just more attention

One head has one learned set of query, key, and value projections. Multi-head attention runs several smaller attention operations in parallel, concatenates their outputs, then mixes them through another learned projection.

In the base model, dmodel=512, h=8, and each head uses dk=dv=64. Eight 64-dimensional heads concatenate back to 512 dimensions before the output projection.

6. The complete block: retrieve, refine, preserve

Attention is only one sublayer. Each encoder layer in the original paper contains multi-head self-attention and a position-wise feed-forward network. Around each sublayer are a residual connection and layer normalization (the original paper’s post-norm arrangement).

z = LayerNorm(x + MultiHeadAttention(x))
output = LayerNorm(z + FFN(z))
FFN(x) = max(0, xW1 + b1)W2 + b2
AttentionMoves information between positions; which tokens communicate depends on content.
Feed-forward networkTransforms each position independently after communication, using the same small network at every position.
Residual pathLets the learned sublayer add a correction to an existing representation rather than replacing it wholesale.
Layer normalizationNormalizes features within a token representation; it is not batch normalization across examples.

Cross-paper bridge inside the mechanism: this is the same residual idea taught by ResNet: a learned branch proposes a change, while a shortcut preserves a stable baseline. Here the objects being refined are token representations, not image feature maps.

7. Sequence order and the three attention sites

Pure attention is permutation-equivariant: if you reorder input vectors, it reorders output vectors in the same way. It has no native notion that “dog bites man” differs from “man bites dog.” The paper adds sinusoidal positional encodings to embeddings, using sines and cosines at different frequencies.

PE(pos, 2i) = sin(pos / 100002i/dmodel)
PE(pos, 2i+1) = cos(pos / 100002i/dmodel)

8. Worked trace: source sentence to next token

  1. Encode the source. Embed source tokens, add positions, and run six encoder layers. Each source representation can now carry information from the full source sentence.
  2. Prepare a shifted target. At training, the decoder receives <start> Das Tier when asked to predict Das Tier schläft. The causal mask stops each position from consulting the later answer.
  3. Build a decoder query. Masked self-attention gives the current target position a representation of what has already been generated.
  4. Retrieve from the source. Decoder cross-attention uses that representation as Q, and encoder outputs as K,V.
  5. Project to vocabulary probabilities. A linear layer and softmax score next tokens. At inference, select or sample one token, append it, and repeat.

Training

The full target is known, so masked decoder positions can be evaluated together. The loss compares each predicted distribution with the next correct target token.

Generation

Only the generated prefix exists. The next-token loop remains sequential even though the architecture contains no recurrent layer.

9. Read the evidence with the right scope

The paper evaluates translation on WMT 2014 English-to-German and English-to-French. Its reported Transformer (big) scores are 28.4 BLEU on English-to-German and 41.8 BLEU on English-to-French. On the latter task, it reports 3.5 days of training on eight P100 GPUs. Those results support the central claim on these benchmarks: the attention-only architecture was highly competitive while offering a more parallel training path.

Base configuration6 encoder layers, 6 decoder layers, dmodel=512, 8 heads, and a 2048-dimensional inner feed-forward layer.
Ablations examineHeads, projection dimensions, model size, dropout, and positional encodings. Learned and sinusoidal positions performed similarly in the reported setting.

Do not over-read the result. BLEU is reference-overlap based and incomplete as a measure of language quality. The original work is a translation paper, not evidence that every attention-only architecture wins on every modality, data regime, or context length.

10. Limits and misconceptions

Quadratic pairing costFor full attention over n tokens, the score matrix has n² entries. Long contexts become expensive in memory and compute.
Weights are not a complete explanationA weight is one routing signal in a multi-layer computation with values, output projections, residual paths, and nonlinear transformations.
Parallel training ≠ parallel generationMasking allows known target positions to be processed at once while preserving the information rule. Decoding remains token by token.
Position is a requirementAttention by itself has no ordered-sequence notion. Position must be supplied or modeled through an additional mechanism.
Misconception: “The Transformer attends to every token equally.”
It can compare each allowed pair, but learned softmax weights determine which values are mixed into each representation. The receptive field is global; the routing is content-dependent.
Misconception: “Multi-head attention is eight copies of the same relation.”
Every head has its own learned projections. The architecture gives heads capacity to form different routing patterns; whether a particular trained head is interpretable is an empirical question.

11. Active recall

  1. Without looking up the formula, name the operations between QKT and the final weighted value mixture.
  2. What tensor shape makes full self-attention expensive, and why?
  3. What is the information difference between masked decoder self-attention and cross-attention?
  4. Why does dividing by √dk help optimization?
  5. Which part communicates across token positions, and which transforms each token separately?
  6. Why can decoder training be parallel while generation remains sequential?
Open the answer key
  1. Scale the score matrix by √dk, apply softmax row-wise to obtain attention weights, then multiply those weights by V to form weighted value mixtures.
  2. The n × n score/weight matrix. Full self-attention compares every allowed token pair, so its memory and compute grow quadratically with sequence length.
  3. Masked decoder self-attention reads only earlier and current target-side positions; cross-attention uses decoder representations as queries and encoder outputs as keys and values, retrieving source-side information.
  4. Dot-product magnitudes tend to grow with key dimension. Scaling keeps softmax from becoming too peaked too early and preserves useful gradients.
  5. Attention communicates across positions; the position-wise feed-forward network transforms each token independently after that communication.
  6. During training the full target sequence is known, so masked positions can be evaluated together. During generation only the produced prefix exists, so each next token must be appended before the next step.

12. Connect it to your mental map

ResNet teaches a refinement pattern: keep a stable representation on the shortcut, and let a learned branch propose an additive correction. Transformer sublayers use the same grammar around attention and feed-forward transformations. ResNet’s objects are visual feature maps; the Transformer’s objects are token representations that can first exchange information.

DQN and the Transformer share a different discipline: information rules matter. DQN stabilizes a moving learning target with replay and a target network; the decoder prevents target leakage with a causal mask. In both cases, a small rule about what may influence an update changes whether the learning problem is well posed.

GANs emphasize that a network’s behavior comes from the information and objective it receives, not merely from a named layer. Ask in every new architecture: what entities are updated, what may they consult, and what pressure makes the update useful?

13. Takeaway

Native intuition: a Transformer layer is a learned roundtable. Each token asks a question, scores the other allowed tokens’ keys, gathers a weighted mixture of their values, then refines that message through a feed-forward transformation. Residual paths preserve what was already known; position and masking state what information is available. Stack the rounds, and token representations become context-aware without recurrence.
