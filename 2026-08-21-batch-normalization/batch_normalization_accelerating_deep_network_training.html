Batch Normalization

A batch-normalized layer first makes its incoming features comparable, then learns the scale and offset that the network actually wants.

The stable measuring tape

Imagine every layer receiving measurements whose typical size keeps changing while earlier layers learn. Batch Normalization gives each mini-batch a fresh measuring tape: center, scale, then hand the layer a learned way to stretch and shift the result again.

1. The problem: a moving input distribution

A deep layer does not receive raw pixels. It receives activations produced by earlier layers, whose weights change after every update. Their scale and mean can drift. The paper calls this internal covariate shift and proposes normalizing each mini-batch as part of the architecture.

IntuitionIt is easier to tune an instrument when the markings on its dial stay interpretable. BN makes feature coordinates more consistently scaled while learning proceeds.
Important nuanceBN works well, but later work questions whether reducing internal covariate shift is the complete causal explanation. Treat the paper’s term as its motivation, not settled proof of why every benefit occurs.

2. The batch-normalization transformation

μB = (1/m) Σ xi    σ²B = (1/m) Σ(xi − μB)²
x̂i = (xi − μB) / √(σ²B + ε)
yi = γx̂i + β
μB, σ²B Mean and variance measured from the current mini-batch, separately for each feature/channel.
x̂, εCentered-and-scaled activation; ε is a small numerical guard against division by zero.
γLearned scale. It can amplify, shrink, or flip a normalized feature.
βLearned shift. It can move a feature’s useful baseline away from zero.

The learned pair γ, β matters: normalization does not force a layer to keep only zero-mean, unit-variance outputs. It gives optimization a stable coordinate system, then lets the model choose a useful representation within it.

3. Run one batch through the measuring tape

Choose the feature values

Static reading: With values [2, 4, 6, 8], the batch mean is 5. After centering and dividing by its standard deviation, the values are balanced around zero. The learned γ and β then decide the representation the next layer sees.

Worked trace

For x = [2, 4, 6, 8], μB = 5 and σ²B = 5. Ignoring tiny ε for readability:

x̂ ≈ [−1.34, −0.45, 0.45, 1.34]
if γ = 2 and β = 1, then y ≈ [−1.68, 0.10, 1.90, 3.68]

The output is not forced back to zero mean or unit variance. The network can learn to use a stretched and shifted version; it simply starts from a normalized coordinate system for this batch.

4. Training and inference are different moments

During trainingBN uses the current mini-batch’s mean and variance. This means one example’s output depends slightly on its batch companions.
During inferenceA deployed model cannot rely on a convenient batch. It uses accumulated running estimates of mean and variance instead, making each prediction deterministic with respect to its input.
Practical implication: batch size and batch composition matter. Very small or unusual batches can make the estimates noisy; alternatives such as LayerNorm or GroupNorm may be preferable depending on the architecture and setting.

5. What the paper showed—and did not show

The paper reports that its batch-normalized Inception model reached the reference accuracy with 14× fewer training steps, and its ensemble reached 4.9% top-5 validation error and 4.8% test error on ImageNet. It also reports tolerance for higher learning rates and less careful initialization in its studied models.

Those results do not mean BN is universally the right normalization layer, that it removes tuning, or that it alone explains every improvement. Its behavior depends on placement, batch regime, task, architecture, and training setup.

6. Check your model

Does BN normalize a whole layer with one shared mean?

No. It computes statistics per feature or convolutional channel (over the relevant batch and spatial elements), not one global number for every feature.

If normalization is useful, why add γ and β?

They preserve expressive freedom. The model can select the scale and offset that serve the task after standardization.

Can training-time batch statistics be used blindly at inference?

No. A single example or a differently composed batch would produce a different result. BN normally uses stored running estimates at inference.

Is BN the same as LayerNorm?

No. BatchNorm relates examples through batch statistics; LayerNorm normalizes features within an individual example. This is one reason Transformers commonly use LayerNorm.

7. BatchNorm for convolutional feature maps

For a convolution output X ∈ ℝN×C×H×W, BatchNorm gives each channel its own measuring tape. For channel c, it pools values across the batch and every spatial position:

μc = (1/NHW) Σn,h,w Xn,c,h,w
σ²c = (1/NHW) Σn,h,w(Xn,c,h,w − μc)²
What is sharedThe same μc, σ²c, γc, βc apply to every spatial location in one channel.
What stays separateDifferent channels do not share statistics. An edge detector and a texture detector get independent normalization parameters.
Trace it: for N=4, C=64, H=W=28, one channel’s statistics use 4 × 28 × 28 = 3136 values. Not four values, not one value per pixel, and not all channels mixed together.
Predict before revealing: what changes for a fully connected layer?

For a dense layer shaped N × D, each feature dimension uses its statistics across the N examples. There are no spatial axes to pool.

8. The running-statistics notebook

Training needs the current batch. Deployment needs a stable estimate that does not depend on which examples happen to arrive together. A running mean can be updated with a small update rate α:

At inference, an activation uses stored running statistics: y = γ(x − μrunning) / √(σ²running + ε) + β. Frameworks use different names and conventions for “momentum,” so check the documented formula rather than assuming the coefficient’s meaning.

Why can train mode and eval mode change a CNN prediction with identical weights?

Only the statistics changed. Train mode measures the current batch, so one image’s output can depend on its neighbours. Eval mode uses stored estimates, making the output independent of its batch companions.

9. BN inside a residual network

Classic convolutional blockConv → BN → ReLU. BN normalizes the convolution’s channel outputs before the nonlinearity.
Original ResNet-style branchx → Conv → BN → ReLU → Conv → BN, then add the shortcut and apply ReLU. Pre-activation ResNets instead place BN → ReLU before each convolution.

These layouts are design choices, not interchangeable slogans. The shortcut remains the baseline information route; BN does not replace it. When a branch changes 56×56×64 into 28×28×128, the shortcut needs the learned projection you studied in the ResNet lesson so addition is valid.

Predict before revealing: Can a shortcut with shape 56×56×64 be added directly to a residual branch with shape 28×28×128? No. Addition is elementwise, so both the spatial grid and channel count must align first.

10. When the measuring tape becomes noisy

BN does not “always fail” with small batches, but its estimates become less reliable when too few values contribute. CNNs can still have many samples per channel through N×H×W; late layers with small feature maps lose that help.

Tiny N or tiny H×WBatch mean and variance fluctuate more. With only one value per channel in a training step, variance estimation can be unusable.
Distributed and fine-tuning regimesPer-device batches may be too small. Options include synchronized BN, freezing running statistics, or choosing another normalization family; each has trade-offs.

Gradient accumulation does not automatically give BN the statistics of the accumulated effective batch: it sees each forward pass separately. Under domain shift, stale running estimates can also be a real source of mismatch.

Practice: choose a likely starting point

A large-batch image classifier often makes BatchNorm a strong baseline. A Transformer commonly uses LayerNorm because each token can be normalized independently of batch composition. A vision detector constrained to 1–2 images per device often makes GroupNorm a practical candidate. These are starting points, not laws.

12. Connect it to your mental map

ResNet: residual shortcuts preserve a direct route for representations and gradients; the original ResNet also used Batch Normalization in its residual branch. One makes refinement paths easy; the other makes the branch’s feature scale easier to manage. Transformer: it also uses residual additions, but commonly relies on LayerNorm because each token can be normalized independently of batch composition, which fits variable-length and autoregressive sequence work naturally. DQN: replay buffers change which samples arrive together, so batch statistics are not a universal stability solution; replay and target networks instead stabilize bootstrapped targets. GAN: generator and discriminator distributions move while training, making normalization choices consequential but not a substitute for game stability.

Question to carry forward: when you meet a normalization layer, ask: which axes are averaged together, when are the statistics computed, and what train-versus-inference behavior follows?

13. Takeaway

Native intuition: Batch Normalization is a learned measuring tape inside a network. For each mini-batch it recenters and rescales feature values, then gives the model learned knobs to choose the useful scale and offset again. The stable coordinates help learning; the learned affine step keeps representation power.

Answer key

Model answer: “BatchNorm differs from LayerNorm because …”

BatchNorm measures each feature or channel across the mini-batch (and spatial positions for CNNs), so training examples influence one another and inference uses stored running statistics. LayerNorm measures features within each individual example or token, so it does not depend on batch companions.
