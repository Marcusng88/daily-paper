Graph machine learning · a 60-minute active study

A node learns by listening—without becoming its neighbours.

A Graph Convolutional Network (GCN) classifies connected objects by repeatedly mixing each node’s own features with a degree-normalized summary of nearby nodes. The important story is not only the layer equation: it is how a few known labels teach the shared mixing rule for every node.

01 / Start with the task, not the formula

Only some papers reveal their topic.

Imagine a citation network. Each node is a paper; its row in X contains word features; an edge says two papers cite one another after the graph is made undirected. We want a topic label for every paper, but only a small set of papers comes with a known topic.

Semi-supervised, transductive means: the whole network, all feature rows, and all edges are available during training; the loss is calculated only on the labelled nodes. Think of an open-book class where everyone’s notes and seating chart are visible, but only a few answer sheets are marked. The marked sheets teach a rule that is then applied to every student. Labels themselves are not passed along edges as features.

Independent baseline: MLP

Apply the same classifier to each feature row. It can read a paper’s words but cannot use who it connects to.

GCN question

How can a node turn its own information and its neighbourhood into a better representation, using the same learnable rule everywhere?

That question connects this paper to earlier lessons. A CNN uses the same local rule over a fixed pixel grid; a GCN uses it over the irregular neighbourhood supplied by graph edges. A Transformer also mixes related items, but learns which pairs attend to one another; the original GCN takes the graph’s adjacency as fixed.

Predict before continuing

A paper has vague words but links mainly to machine-learning papers. Can an independent MLP use those links? Can a GCN?

Answer

The MLP cannot: it receives only that paper’s feature row. A GCN can, because its update includes feature information from connected nodes. This only helps when graph neighbours carry relevant signal; it is not a guarantee that connections mean the same class.

02 / One layer, in human order

Keep yourself. Hear your neighbours. Scale the volume. Then learn a lens.

Before reading one large matrix equation, separate the four jobs. Adding self-loops lets a node retain its own current representation. Aggregation collects local evidence. Degree normalization stops a well-connected hub from making every individual edge excessively loud. A learned matrix then turns the mixture into features useful for classification.

03 / Worked trace A

Calculate one representation, not just the formula.

Let target node v be connected to neighbour u. After self-loops, both degrees are 2. Use one-number features xv=2 and xu=6, take W=1, and momentarily use the identity for σ so we can see the arithmetic.

hv′=12×2·2+12×2·6=0.5·2+0.5·6=4

Node v did not become u. Its new representation is a balanced mixture of its own feature and its context. With real vector features, W learns which mixtures are helpful: perhaps a “neural” word feature together with neighbours using “gradient” signals a machine-learning topic.

Predict before revealing

If the edge to u disappears, what reaches v after the self-loop is kept?

Answer

Only v speaks to itself, so its degree is 1 and its self-loop weight is 1. The pre-activation is 2. The change from 4 to 2 happens even though v’s own feature never changed: graph structure changed the representation.

This one layer sees one hop. A second layer applies the same local operation to already-mixed representations, allowing v to receive information from two-hop nodes. That is the useful reason to stack layers—not simply “more layers are better.”

04 / From a representation to a learned classifier

Few labels train shared weights; every node receives a prediction.

The paper’s basic transductive classifier has two layers. The first collects one-hop evidence and applies ReLU. The second collects again, so each logit can depend on two-hop context. Softmax turns final logits into class probabilities.

Why can two labelled nodes teach unlabelled ones? W is shared across every row, just as a CNN filter is shared across pixels. A labelled node says “make this kind of neighbourhood produce this topic.” Gradient descent adjusts the shared lens; the same adjusted lens is then used to calculate Z for unlabelled nodes. This is not label leakage: unlabelled target labels never enter the loss.

Worked trace B: logits become a loss signal

Suppose a labelled paper’s correct topic is class 1, but the two-layer GCN currently produces logits [2, 1] for classes [0, 1]. Softmax assigns class 1 probability about 0.27, so the loss is −log(0.27) ≈ 1.31: high, because the correct class did not receive enough probability. Backpropagation changes W(0) and W(1), not the paper’s supplied label or adjacency.

Decision check

An unlabelled node has a row in Z, but is it included in the training loss?

Answer

No. It participates in message passing because the full graph is used, and receives a prediction at inference, but its unknown target label is absent from the masked loss. This full-graph setup is why the experiment is called transductive.

05 / Instrument: inspect one edge weight

Neighbours are not all equally loud.

For an edge from source j to target i, the normalized contribution has weight 1 / √(dᵢdⱼ). Keep the target degree at 2 and change the source degree. Predict first: when j becomes a hub with many neighbours, should this single edge’s weight rise or fall?

0.500

At degrees 2 and 2, this source contributes weight 0.5 along this edge.

Answer to the prediction

It falls. With a hub source degree of 8 and target degree 2, the edge weight is 1 / √(2 × 8) = 0.25. Normalization controls scale across uneven connectivity; it does not mean every neighbour contributes the same feature or determines whether a neighbour is semantically useful.

One layer

v hears its direct neighbours’ current features.

Two layers

v hears neighbours whose current representations already contain their own neighbours’ features: a two-hop receptive field.

Diagnostic: can a two-hop node influence v after one layer?

No. It must first influence v’s intermediate neighbour during layer 1. Then that updated neighbour can influence v in layer 2. Stacking layers expands graph distance, but too many averaging layers can make node representations too alike.

06 / Where did this simple rule come from?

A local approximation replaced a costly spectral operation.

The paper begins with spectral graph convolutions and a Chebyshev-polynomial approximation. It then makes a first-order approximation and ties parameters, producing a local operation that looks like normalized adjacency propagation. You do not need to reproduce the spectral derivation to use the central idea: the approximation changes a graph-wide eigendecomposition problem into a sparse local rule.

That choice explains the practical claim. A propagation step is linear in the number of edges rather than requiring a full spectral decomposition. In the paper’s transductive setup, training is full-batch: the whole graph is processed together, with sparse adjacency storage scaling with the number of edges.

Keep the claim precise. “Linear in edges” describes the propagation operation under this sparse implementation. It does not mean arbitrary gigantic graphs are effortless: the full relevant graph and its multi-hop neighbourhoods still need to be available for the pass.

07 / What the paper actually established

Strong citation-network results, under a particular setup.

The paper compares its two-layer GCN with prior methods on semi-supervised node classification. On the standard citation-network splits, it reports the following test accuracies.

Read this as an accuracy under the paper’s benchmark split and transductive setting—not a universal score for graph learning.

The paper’s ablation makes the point more concrete: on Citeseer/Cora/Pubmed, its renormalization model reports 70.3/81.5/79.0%, compared with 46.5/55.1/71.4% for an MLP that cannot use graph structure. This supports the claim that normalized neighbourhood aggregation can exploit the relational signal in these datasets.

Limits you should carry forward. Citation graphs are often homophilous: linked papers tend to share a topic. If edges commonly connect unlike classes, simple neighbour averaging can damage a representation. The model is also transductive, assumes a static unweighted adjacency, and the paper reports that deeper versions above roughly seven layers train poorly without residual connections—an early warning about depth and over-smoothing.

08 / Diagnose your model

Can you connect the pieces without the page?

Why add self-loops before aggregating?

So a node’s own current representation is included. Without a self-loop, a layer can replace a node’s information entirely with its neighbours’ mixture.

What is fixed, and what is learned in the basic GCN?

The adjacency A and input features X are graph inputs for the pass. Degree normalization is determined by A. The W matrices are learned from the masked classification loss.

Why does a labelled-node loss affect an unlabelled node’s prediction?

Because the learned W matrices are shared across all nodes. Labels update the common feature lens, then the graph layer applies that lens to every node’s representation.

What does normalization solve—and what does it not solve?

It controls message magnitude across nodes with different degrees. It does not decide semantic relevance, repair misleading edges, or make a graph heterophily-friendly by itself.

Connect it to your mental map

GCN extends the shared local computation of the CNN and ResNet branch beyond rectangular image grids: neighbourhoods come from edges. It resembles the Transformer’s information mixing, but uses fixed graph topology and degree normalization rather than learned attention weights. Like DQN, it learns a representation used for a downstream decision, but its loss supervises node classes rather than action values. Its shared matrices are learned by the same gradient-based optimization ideas that Adam helps stabilize.

Takeaway

A GCN is a trainable local listening rule: retain each node’s own signal, take degree-bounded evidence from connected nodes, transform that mixture with shared weights, and use sparse known labels to make the rule useful everywhere in the graph.
