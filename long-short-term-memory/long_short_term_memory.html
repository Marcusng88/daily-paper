A protected state lane · Neural Computation, 1997

Memory only helps if learning can reach it.

Long Short-Term Memory made a precise architectural bargain: reserve one recurrent route for carrying state and error, then put learned gates around access to it. This lesson follows the original two-gate design, not the later shorthand.

Prerequisite bridge

A message can survive forward and still be impossible to teach backward.

Picture a 100-person relay. Each person passes a note forward. At the finish, a coach sends back a correction: “the first note was important.” A conventional recurrent network uses a transformation at each handoff, so the backward correction is repeatedly scaled by local derivatives and weights. It often becomes tiny long before it reaches the relevant moment.

∂L∂st=∂L∂st+k×∏r=1∂st+r∂st+r−1k

Read the product as “every sensitivity on the path.” If an effective factor is 0.7 at each step, ten steps leave 0.710 ≈ 0.028; one hundred leave about 3.2 × 10−16. The 1997 paper calls this an exponentially decaying error problem.

The design target: create a state path whose direct self-connection has derivative 1. The paper calls it a Constant Error Carousel (CEC). That preserves a designated route for credit across time—but a useful memory still needs selective access.

1 · The motivating failure

A perfect loop remembers too indiscriminately.

A linear self-loop with weight 1 can carry state and its direct derivative unchanged. But it cannot answer two contextual questions: should the current input be written into memory, and should memory influence the current output? If every input writes, irrelevant events corrupt the stored clue. If memory is always exposed, it can interfere with behavior that should ignore it.

This is the paper’s key separation. The input gate controls additions to the private state. The output gate controls how much transformed state becomes public. The widely taught forget gate is a later extension; it is absent from the original architecture.

The original cell state equation has an addition, not a forget multiplier: prior state persists while the input gate determines how much candidate content gets added. Thus output gating can hide a state without erasing it.

3 · Mechanism

Writing, carrying, and reading are three different actions.

Cells do not work alone. Gate units, memory cells, ordinary hidden units, inputs, and outputs are recurrently connected in the networks used by the paper. The cell is a specialized component inside that larger circuit.

4 · Worked trace A

Follow a fact through noise without treating memory as magic.

Use one scalar cell as a stand-in for a clue: the first token says “meeting: Thursday”; later tokens are chatter; a question arrives at the end. The numbers are illustrative, while the update rule is the paper’s.

Write the clue. Start at 0. Candidate = 0.9 and the input gate is 0.8.

s₍c₎(1) = 0 + 0.8 × 0.9 = 0.72

Ignore chatter. The next candidate is −0.7, but its input gate is only 0.02.

s₍c₎(2) = 0.72 + 0.02 × (−0.7) = 0.706

Hide the clue until useful. If the output gate is 0.05, little of h(0.706) is exposed. When a question arrives and the output gate rises to 0.90, the still-stored state becomes available.

Predict before reveal. Suppose the output gate stays at zero for ten steps while input gates remain closed. What happens to the stored state?

It can remain stored. Closing the output gate blocks exposure, not the cell-state update. With no admitted input, the CEC carries the old state forward on its direct path.

5 · Worked trace B

The CEC protects the middle of a credit path, not every derivative everywhere.

Imagine a later loss assigns unit credit to a state four steps earlier. Along the designated CEC carry path, the state-to-state derivative is 1 at each intermediate step under the paper’s architecture-specific truncated backpropagation.

CEC direct route: 1.00 × 1 × 1 × 1 × 1 = 1.00
ordinary route, factor 0.7: 1.00 × 0.7⁴ = 0.2401
ordinary route after 100 steps: 0.7¹⁰⁰ ≈ 3.2 × 10⁻¹⁶

The narrow but important claim is that LSTM avoids paying a fresh shrinking or exploding factor at each intermediate CEC step. Error still has to enter through output-related derivatives and leave through input/candidate derivatives. This is a protected route, not a universal optimization guarantee.

Historical precision: the paper explicitly notes that state drift can saturate output nonlinearities, and it uses negatively biased input gates to counter unwanted accumulation. “Derivative one” is not permission to ignore every other path in the network.

6 · Evidence

The experiments test long lag under controlled conditions.

The paper does not claim a modern benchmark crown. Instead, it constructs tasks where the signal appears long before the target and asks whether learning can bridge that delay. That directly tests the problem the architecture was built to solve.

The paper's learning rule keeps only derivatives of cell state with respect to relevant incoming weights, giving O(W) work per time step. It deliberately truncates error that arrives at cell-input and gate nets through time while preserving the CEC's within-cell state path: local in space and time, rather than a claim that all sequence history is back-propagated.

7 · Limits and misconceptions

Know exactly what the original idea says—and what it does not.

“The original LSTM has input, forget, and output gates.”

Not in this paper. It has input and output gates around a Constant Error Carousel. The forget gate that appears in many later LSTM formulations was introduced afterward.

“A derivative of one means no gradient can vanish.”

No. The constant-error result refers to the protected intermediate CEC route under the stated training treatment. Entry, exit, nonlinearities, and other paths can still weaken the overall learning signal.

“LSTM stores an exact record forever.”

No. Its state can receive additions when input gates open, output nonlinearities can saturate, and the representation is learned rather than a literal database entry. It gives the network a controllable persistence mechanism.

“The tables prove LSTM wins every long-context problem.”

No. They support a narrower, stronger historical claim: in these artificial long-delay experiments, LSTM solved cases where listed comparison methods did not. Later tasks and architectures change the tradeoffs.

8 · Active recall

Can you reconstruct the causal story without the diagram?

Why does ordinary recurrence struggle with a distant credit assignment?

Its backward signal repeatedly multiplies local derivatives and recurrent weights. Unless the effective product stays near one, it tends to vanish or explode exponentially with the number of steps.

What is the Constant Error Carousel?

The memory cell’s fixed self-recurrent internal-state connection. Its direct derivative is one, creating a route that can carry error without repeated time-dependent scaling.

What job does the input gate perform?

It controls how much candidate content gets added to the cell state. Closing it protects previously stored state from current input.

What job does the output gate perform?

It controls how much transformed cell state becomes visible to the rest of the network. Closing it can hide a memory without deleting it.

What is the careful conclusion from Table 2?

For the reported 100-step-delay task, the listed LSTM runs achieved 100% success while listed BPTT and RTRL rows achieved 0%. It is evidence about that experiment, not a universal ranking.

9 · Deepen the mechanism

A gate is a learned, context-sensitive scale—not a hand-set switch.

The symbols yin and yout are activities computed by units in the recurrent network. The paper lets their input come from input units, other gate units, memory cells, and ordinary hidden units. That is the missing causal step: context is first mixed into a net input, then a gate activation turns that net input into a multiplier on writing or reading.

netj(t)=∑uwjuyu(t−1),yj(t)=fj(netj(t))

Two layers of interpretation

Mix: the weighted sum collects evidence about the current situation. Scale: the gate converts that evidence into a permission. In the paper’s reported Experiment 1, gate activations are logistic sigmoids with output range [0, 1]; near 0 almost closes a route and near 1 almost opens it.

The paper also defines a memory cell block: several cells may share one input gate and one output gate. A shared gate can therefore admit or expose a multi-component, distributed representation together. A block of size 1 is the single-cell picture used in this lesson.

The diagram’s teal and rust multipliers are therefore not extra storage. They are learned valves, each informed by the network’s recent state, placed around the persistent state lane.

∂sc(t)∂sc(t−1)=1

So the direct contribution across k intermediate carry steps is a product of ones. Error entering through the output gate is first scaled by youth′; inside the CEC it is not repeatedly rescaled; leaving toward the cell-input weights scales it through ying′ and is then truncated in the paper’s training treatment. The CEC protects the long middle of credit assignment—not every derivative in the whole network.

11 · Interpret the evidence

Table 2 asks whether a cue can survive a long stretch with no local shortcut.

The p=100 task, in plain language

  1. The network receives one of two cue symbols, x or y.
  2. It then sees 99 fixed intervening symbols, making the cue-to-target delay p=100.
  3. The final target repeats the first cue, so nearby inputs cannot determine the answer.
  4. A reported success requires maximal absolute error below 0.25 for every output across 10,000 successive random sequences.

At p=100, Table 2 reports LSTM at 100% successful trials and success after 5,040 presentations. BPTT and RTRL report 0% and no success within five million presentations; neural sequence chunking reports 33%. The entries are means of 18 trials. This is controlled evidence about long-lag credit assignment, not a verdict on every sequence task.

The direct CEC carry path. Along its protected middle, the state-to-state derivative is one rather than a fresh, potentially shrinking factor at every step. Input, output, and nonlinear derivatives still matter at entry and exit; the diagram is not claiming every gradient path is constant.

12 · Final recall

Rebuild the complete claim after seeing the evidence.

Why is the p=100 cue task diagnostic rather than merely difficult?

The final target repeats the first cue after 99 fixed intervening symbols. Nearby inputs cannot determine it, so useful credit has to cross the long delay.

Which derivatives does the CEC protect, and which does it not?

It protects the direct intermediate state-to-state path inside the cell. Error still crosses output-gate and output-nonlinearity derivatives on entry, and input-gate and candidate derivatives when assigning credit to cell-input weights.

What does a memory-cell block add beyond the single-cell picture?

Several cells can share one input gate and one output gate, so a learned context can admit or expose a distributed group of stored components together.

What does Table 3's 49,000 versus 203,000 comparison show?

At the same 1000-step minimum lag, making 50 distractor types recur about 20 times instead of using 1,000 types with recurrence 1 increases mean presentations to success. The source task's distractor structure affects learning difficulty.

Connect it to your mental map

One solution to long credit: change the route itself.

The back-propagation lesson gives the general reason long chains can weaken learning signals. LSTM applies that diagnosis in time: reserve a recurrent state route whose direct derivative stays controlled, then gate access to it. Neural Turing Machines extend the memory question outward by letting a controller read and write a larger addressable store. Transformers make a different bet, using attention to retrieve distant token representations directly instead of compressing all prior context into a fixed-size recurrent state.

Takeaway

An LSTM is a protected notebook line with two permissions.

The Constant Error Carousel preserves a dedicated state-and-credit route across delay. The input gate grants permission to write; the output gate grants permission to use what is stored. That separation lets a sequence model ignore noise without automatically discarding the fact that will matter later.
